# Synthetic room map

map.png is a96×64 RGB PNG created in code for the native H5P authoring fixture. It shows a white diagonal on an orange field. It is not a real venue map and contains no personal or location data.

SHA-256: c538d3c97b12004b2df166547fe6b77edf74effbde2303ea8c31f6195fb7c152

The independent oracle pins these original bytes before merger implementation. The native editor uploads this image for moduleC; its packaging path is later normalized to images/map.png to test a collision with the different registration-map bytes.
