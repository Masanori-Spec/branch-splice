# Synthetic registration map

map.png is a96×64 RGB PNG created in code for the native H5P authoring fixture. It shows a white cross on a blue field. It is not a real venue map and contains no personal or location data.

SHA-256: f355baa1b1ac3d395ee5d5677cd03a2eb098d02020350a053bec14c719c32caf

The independent oracle pins these original bytes before merger implementation. The native editor uploads this image for moduleB; its packaging path is later normalized to images/map.png to test a collision with the different room-map bytes.
